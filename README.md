# Opportunity Dataset — Team Project

This repository contains my work from a team-based data preparation and data visualisation project using the Opportunity Dataset.

The project was completed as part of the Excelerate Data Visualization Trainee Program. I have kept the original project files and presentation material in the repository rather than replacing them with a simplified version.

## What this project contains

- Opportunity Dataset cleaning and preparation
- data-quality checks and documented cleaning decisions
- exploratory data analysis
- charts and visual analysis
- team presentation material
- Power BI dashboard material
- supporting reports and cleaned spreadsheet

## My contribution

My contribution was mainly around data cleaning and data-quality review, together with analysis work completed as part of the wider team.

The project should therefore be read as **team work**, not as an individual research study.

## Data preparation

The preparation work included:

- inspecting the original dataset structure
- reviewing fields and data types
- checking missing and unusual values
- reviewing duplicate records
- standardising dates and recognisable formatting issues
- checking image-link structure
- documenting cleaning decisions
- keeping the source information separate from working changes where possible

I did not treat missing information as something that should automatically be replaced with a guessed value. The meaning of a field was considered before making a change.

## Week 2 analysis

The Week 2 workbook and report build on the prepared dataset and include analysis of:

- opportunity creation trends
- opportunity categories
- locations
- scholarship information
- category relationships
- data-quality limitations
- visual summaries and charts

An important limitation is that the dataset is opportunity-level rather than application-level. Therefore, location analysis describes **opportunity volume by location**, not the number of applications. The dataset also does not provide an outreach/discovery-channel field, so outreach-channel performance cannot be directly measured from this data.

## Presentation and visual design

The original presentation and dashboard files are preserved in this repository.

I have **not recreated the visual layout in Markdown** because doing that would lose the original Power BI/PowerPoint formatting. The .pbix, .pptx, PDFs and spreadsheet should be opened in their appropriate applications to see the original charts, page layout, typography, spacing and presentation structure.

Where fonts, SVG/vector elements or other visual assets are embedded inside the PowerPoint or Power BI files, they remain part of those original files. I have not replaced them with newly generated graphics.
